# 实战 05：ADC → PWM 闭环控制

## 接线
- MCU VDD → +3.3V；VSS → GND
- PA1 → 电位器 W（0..3.3V）
- PA0 → 探针 / LED 限流电阻网络

## 工作原理
ADC1 规则序列采集通道 1（PA1）。EOC 置位后读取 12 位 DR 值，再把它映射到 TIM2_CCR1；PSC=7、ARR=99，在 8MHz 定时器输入下目标 PWM 频率为 10kHz。这里的 PWM 占空比由真实固件寄存器写入控制，不是 UI 动画。

## 动手任务
1. 编译运行并把探针接 PA0。
2. 慢慢拖动电位器，观察 PA1 电压与 PA0 PWM 占空比同步变化。
3. 把 5..95% 范围修改为 10..80%，解释限幅如何影响输出。
4. 固定 PA1 电压，在示波器上比较占空比稳定性。

## 验收
PA0 维持约 10kHz；低/中/高电位器输入对应不同占空比。若只有电压变化而占空比不变，检查 ADC1 EOC / DR 与 TIM2_CCR1 的写入链。
