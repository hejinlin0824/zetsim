# 实战 06：PWM + RC 低通滤波

## 接线
- PA0 → 1kΩ 电阻 → 滤波节点
- 滤波节点 → 100nF 电容 → GND
- 探针并接滤波节点；建议再用另一个探针对比 PA0 原始 PWM

## 原理
PWM 的 3.3V 峰值、30% 占空比给出理想平均值约 0.99V。RC 时间常数为 τ=R×C=1kΩ×100nF=100µs；电容让输出不能瞬间变化，形成较小的锯齿纹波。

## 动手任务
1. 编译运行本项目，确认 PA0 约为 10kHz、30% 占空比。
2. 手动搭建 RC 节点并连接探针。
3. 把 100nF 改成 220nF，比较纹波与响应时间。
4. 保持元件参数不变，把 `PWM_DUTY` 从 30 改成 60，预测并验证平均输出电压变化。

## 验收
原始 PA0 是方波，RC 节点更平滑；平均值接近 0.99V（30% duty），改变 R/C 后纹波和响应速度有可观察变化。数值允许受仿真时间步长影响。
