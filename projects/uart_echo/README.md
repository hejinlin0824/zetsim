# 实战 04：USART1 串口回显

## 接线 / 外设约定
- PA9：USART1_TX（Web 终端显示发出的字节）
- PA10：USART1_RX（Web 终端输入注入到芯片）
- 默认 HSI 8MHz，BRR=0x0457，近似 115200 baud

## 学习目标
理解 RCC 时钟、GPIO 复用功能、USART BRR、SR.TXE、SR.RXNE 与 DR 读写。

## 动手任务
1. 编译并运行，在 USART1 输入框发送 `hello`。
2. 修改启动问候语后重新编译。
3. 临时移除 RXNE 判断，观察为什么不能无条件读 DR。
4. 尝试一次发送 20 个字符，确认终端仍能持续交互。

## 验收
启动后看到固件自己的问候语；输入字符后获得固件逐字节回显。当前为轮询版，不依赖 USART 中断向量。
